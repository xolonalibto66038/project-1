# Educational Web Platform

A scalable educational web application built with Django that organizes learning content using a structured academic hierarchy:

Level → Grade → Subject → Course → Resource

The platform provides interactive learning features such as quizzes, assessments, gamification, recommendations, and integrations with external services like Stripe for payments and Zoom for virtual classes.

## Features

- Structured curriculum management
- Quiz and assessment system
- Gamification elements
- Course recommendations
- Virtual classrooms integration
- Secure online payments
- Role-based access (Students, Teachers, Admins)

## Tech Stack

Backend
- Django
- Django REST Framework

Frontend
- Bootstrap
- jQuery
- AdminLTE

Integrations
- Stripe (Payments)
- Zoom (Video conferencing)

Database
- PostgreSQL / SQLite (development)
